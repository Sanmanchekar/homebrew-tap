# Sanmanchekar Homebrew tap

```bash
brew install sanmanchekar/tap/agentglance              # CLI
brew install --cask sanmanchekar/tap/agentglance-app   # menu bar app
```

| Package | What |
|---|---|
| `agentglance` | [AgentGlance](https://github.com/Sanmanchekar/agentglance) CLI: `agentglance ps`, `clean`, `install` |
| `agentglance-app` | AgentGlance menu bar app |
